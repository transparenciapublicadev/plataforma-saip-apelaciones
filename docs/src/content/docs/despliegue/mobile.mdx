## Build de Release

<Steps>
1. **Configurar** la firma del APK/AAB en `app/build.gradle.kts`
   ```kotlin
   android {
       signingConfigs {
           create("release") {
               storeFile = file(System.getenv("KEYSTORE_PATH"))
               storePassword = System.getenv("KEYSTORE_PASSWORD")
               keyAlias = System.getenv("KEY_ALIAS")
               keyPassword = System.getenv("KEY_PASSWORD")
           }
       }
       buildTypes {
           release {
               isMinifyEnabled = true
               isShrinkResources = true
               proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
               signingConfig = signingConfigs.getByName("release")
           }
       }
   }
   ```
2. **Compilar** el bundle de release
   ```bash
   cd mobile
   .\gradlew.bat bundleRelease    # AAB para Play Store
   .\gradlew.bat assembleRelease  # APK directo
   ```
3. **Verificar** el artefacto
   ```bash
   ls app/build/outputs/bundle/release/
   ```
</Steps>

## Variables de Entorno

| Variable | Descripción |
|----------|-------------|
| `KEYSTORE_PATH` | Ruta al archivo .jks de firma |
| `KEYSTORE_PASSWORD` | Contraseña del keystore |
| `KEY_ALIAS` | Alias de la clave de firma |
| `KEY_PASSWORD` | Contraseña de la clave |

## Firebase

El archivo `google-services.json` debe estar en `app/` y configurado para el entorno de producción con:
- **Firebase Auth** — Autenticación de usuarios
- **Firebase Cloud Messaging (FCM)** — Notificaciones push

:::danger[google-services.json]
Este archivo contiene configuración sensible del proyecto Firebase. NUNCA incluir en repositorios públicos — debe estar en `.gitignore` y distribuirse de forma segura al equipo.
:::

## ProGuard / R8

Las reglas de ofuscación están en `app/proguard-rules.pro`. Incluir reglas para:
- Retrofit (DTOs que se deserializan con Gson)
- SQLDelight (entidades generadas)
- Firebase (clases de reflexión)

```text
# Retrofit
-keepattributes Signature
-keepattributes *Annotation*
-keep class retrofit2.** { *; }

# Modelos de red (DTOs)
-keep class pe.gob.misaip.core.network.dto.** { *; }

# SQLDelight
-keep class pe.gob.misaip.core.database.** { *; }
```
