## Variables de Entorno

| Variable | Descripción | Obligatoria |
|----------|-------------|-------------|
| `DB_USERNAME` | Usuario de MySQL | Sí |
| `DB_PASSWORD` | Contraseña de MySQL | Sí |
| `JWT_SECRET` | Clave secreta para firmar tokens JWT (mín. 256 bits) | Sí |
| `SPRING_PROFILES_ACTIVE` | Perfil activo (`prod`, `dev`) | Recomendada |
| `APP_NOTIFICATIONS_MODE` | Modo del motor de notificaciones (`MOCK` o `SMTP`, por defecto `MOCK`) | No (Default: MOCK) |
| `APP_NOTIFICATIONS_MAIL_FROM` | Dirección de remitente para notificaciones por correo | No (Default: no-reply@plataforma-saip.local) |
| `SPRING_MAIL_HOST` | Host del servidor SMTP para notificaciones por correo | No (requerido si mode es SMTP) |
| `SPRING_MAIL_PORT` | Puerto del servidor SMTP para notificaciones por correo | No (Default: 25) |
| `SPRING_MAIL_USERNAME` | Usuario para autenticación SMTP | No |
| `SPRING_MAIL_PASSWORD` | Contraseña para autenticación SMTP | No |
| `SPRING_MAIL_SMTP_AUTH` | Habilitar autenticación SMTP (`true`, `false`) | No |
| `SPRING_MAIL_SMTP_STARTTLS` | Habilitar TLS para conexión SMTP (`true`, `false`) | No |

:::danger[Secrets]
NUNCA hardcodear credenciales. En producción, usar variables de entorno del hosting platform o un gestor de secretos para passwords de BD, JWT y SMTP.
:::

:::caution[Motor de notificaciones]
`MOCK` es exclusivo para desarrollo local y Newman. `SMTP` habilita correo real configurable mediante variables de entorno. `CASILLA_ELECTRONICA` dispone de un adapter preparado que responde `NO_DISPONIBLE` hasta contar con contrato API oficial; no existe fallback automático entre canales.
:::

## Build de Producción

<Steps>
1. **Compilar** el proyecto con Maven
   ```bash
   cd backend
   ./mvnw clean package -DskipTests
   ```
2. **Verificar** el JAR generado
   ```bash
   ls target/saip-backend-*.jar
   ```
3. **Ejecutar** con variables de entorno
   ```bash
   DB_USERNAME=saip_user \
   DB_PASSWORD=secure_password \
   JWT_SECRET=clave_secreta_minimo_256_bits_segura \
   java -jar target/saip-backend-0.0.1-SNAPSHOT.jar \
     --spring.profiles.active=prod
   ```
</Steps>

## Configuración de Producción

```properties
# application-prod.properties
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false
server.port=8080

# CORS — restringir a dominios de producción
app.cors.allowed-origin-patterns=https://misaip.gob.pe
```

:::caution[ddl-auto]
En producción, usar `validate` (NO `update`) para evitar cambios accidentales en el schema. Las migraciones deben ejecutarse de forma controlada.
:::

## Base de Datos

```sql
-- Crear base de datos y usuario
CREATE DATABASE saip_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'saip_user'@'%' IDENTIFIED BY 'secure_password';
GRANT ALL PRIVILEGES ON saip_db.* TO 'saip_user'@'%';
FLUSH PRIVILEGES;
```
