## Variables de Entorno

| Variable | Descripción | Obligatoria |
|----------|-------------|-------------|
| `SPRING_PROFILES_ACTIVE` | Perfil activo. Usar `prod` en producción. | Sí |
| `DB_URL` | JDBC URL de MySQL. | Sí en `prod` |
| `DB_USERNAME` | Usuario de MySQL. | Sí en `prod` |
| `DB_PASSWORD` | Contraseña de MySQL. | Sí en `prod` |
| `JWT_SECRET` | Clave secreta para firmar tokens JWT (mín. 256 bits). | Sí en `prod` |
| `CORS_ALLOWED_ORIGIN_PATTERNS` | Orígenes web autorizados, separados por coma. | Sí en `prod` |
| `APP_NOTIFICATIONS_MODE` | Modo del motor: `MOCK` para local/Newman o `SMTP` para producción. | `SMTP` por defecto en `prod` |
| `APP_NOTIFICATIONS_MAIL_FROM` | Dirección de remitente para correo. | Sí si `APP_NOTIFICATIONS_MODE=SMTP` |
| `SPRING_MAIL_HOST` | Host del servidor SMTP. | Sí si `APP_NOTIFICATIONS_MODE=SMTP` |
| `SPRING_MAIL_PORT` | Puerto del servidor SMTP. | No (Default `prod`: `587`) |
| `SPRING_MAIL_USERNAME` | Usuario de autenticación SMTP. | Sí si `SPRING_MAIL_SMTP_AUTH=true` |
| `SPRING_MAIL_PASSWORD` | Contraseña de autenticación SMTP. | Sí si `SPRING_MAIL_SMTP_AUTH=true` |
| `SPRING_MAIL_SMTP_AUTH` | Habilitar autenticación SMTP (`true`, `false`). | No (Default `prod`: `true`) |
| `SPRING_MAIL_SMTP_STARTTLS` | Habilitar TLS para SMTP. | No (Default `prod`: `true`) |
| `SPRING_MAIL_SMTP_STARTTLS_REQUIRED` | Exigir TLS para SMTP. | No (Default `prod`: `true`) |
| `SPRINGDOC_API_DOCS_ENABLED` | Exponer OpenAPI en producción solo si existe una decisión operativa. | No (Default `prod`: `false`) |
| `SPRINGDOC_SWAGGER_UI_ENABLED` | Exponer Swagger UI en producción solo si existe una decisión operativa. | No (Default `prod`: `false`) |

:::danger[Secrets]
NUNCA hardcodear credenciales. En producción, usar variables de entorno del hosting platform o un gestor de secretos para passwords de BD, JWT y SMTP.
:::

:::caution[Motor de notificaciones]
`MOCK` es exclusivo para desarrollo local y Newman y el perfil `prod` lo rechaza al iniciar. `SMTP` habilita correo real configurable mediante variables de entorno; si faltan host, remitente o credenciales requeridas, el arranque productivo falla con un mensaje claro. `CASILLA_ELECTRONICA` dispone de un adapter preparado que responde `NO_DISPONIBLE` hasta contar con contrato API oficial; no existe fallback automático entre canales.
:::

## Build de Producción

<Steps>
1. **Compilar** el proyecto con Maven
   ```bash
   cd backend
   ./mvnw clean package -DskipTests
   ```
2. **Verificar** el JAR generado
   ```bash
   ls target/saip-backend-*.jar
   ```
3. **Ejecutar** con variables de entorno
   ```bash
   DB_USERNAME=saip_user \
   DB_PASSWORD=secure_password \
   DB_URL=jdbc:mysql://db.internal:3306/saip_db \
   JWT_SECRET=clave_secreta_minimo_256_bits_segura \
   CORS_ALLOWED_ORIGIN_PATTERNS=https://misaip.gob.pe \
   APP_NOTIFICATIONS_MODE=SMTP \
   APP_NOTIFICATIONS_MAIL_FROM=no-reply@misaip.gob.pe \
   SPRING_MAIL_HOST=smtp.example.net \
   SPRING_MAIL_USERNAME=saip_mailer \
   SPRING_MAIL_PASSWORD=secret_manager_reference \
   java -jar target/saip-backend-0.0.1-SNAPSHOT.jar \
     --spring.profiles.active=prod
   ```
</Steps>

## Configuración de Producción

```properties
# application-prod.properties
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false
server.port=8080

# CORS — restringir a dominios de producción
app.cors.allowed-origin-patterns=https://misaip.gob.pe
```

:::caution[ddl-auto]
En producción, usar `validate` (NO `update`) para evitar cambios accidentales en el schema. Las migraciones deben ejecutarse de forma controlada.
:::

## Base de Datos

```sql
-- Crear base de datos y usuario
CREATE DATABASE saip_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'saip_user'@'%' IDENTIFIED BY 'secure_password';
GRANT ALL PRIVILEGES ON saip_db.* TO 'saip_user'@'%';
FLUSH PRIVILEGES;
```

## Verificación

```bash
# Verificar OpenAPI spec
curl http://localhost:8080/v3/api-docs

# Consultar estado seguro del motor con un JWT válido
curl -H "Authorization: Bearer $JWT" \
  http://localhost:8080/api/notificaciones/motor/estado
```

El endpoint de estado expone únicamente modo, capacidades y si SMTP está configurado. Nunca retorna hosts, usuarios, passwords, tokens o secretos.

## Checklist Pre-Producción

- Activar `SPRING_PROFILES_ACTIVE=prod`.
- Cargar BD, JWT y SMTP desde variables de entorno o gestor de secretos.
- Confirmar que `APP_NOTIFICATIONS_MODE=SMTP`; `MOCK` no inicia en `prod`.
- Restringir `CORS_ALLOWED_ORIGIN_PATTERNS` a dominios productivos.
- Mantener OpenAPI y Swagger UI deshabilitados salvo necesidad operativa aprobada.
- Mantener la consola H2 deshabilitada y sin exposición pública.
- Ejecutar migraciones controladas antes de iniciar con `ddl-auto=validate`.
- Consultar `/api/notificaciones/motor/estado` con JWT válido y verificar `smtpHostConfigurado=true`.
- Ejecutar tests, build, Newman en modo local `MOCK` y auditoría de secretos antes del despliegue.
