## Patrón de Componente

```typescript
@Component({
  selector: 'app-solicitud-detalle',
  changeDetection: ChangeDetectionStrategy.OnPush,
  imports: [NgIcon, RouterLink, DatePipe],
  providers: [provideIcons({ heroDocumentText })],
  template: `
    @if (loading()) {
      <div class="flex justify-center p-8">
        <span class="animate-spin">⏳</span>
      </div>
    } @else if (solicitud()) {
      <div class="bg-white rounded-lg shadow p-6">
        <h2 class="text-xl font-bold">
          {{ solicitud()!.expediente }}
        </h2>
        <!-- Contenido -->
      </div>
    }
  `,
})
export class SolicitudDetalleComponent {
  // Inyección con inject()
  private readonly solicitudService = inject(SolicitudService);
  private readonly route = inject(ActivatedRoute);

  // Estado con signals
  solicitud = signal<Solicitud | null>(null);
  loading = signal(false);
  error = signal<string | null>(null);

  // Estado derivado con computed
  estadoColor = computed(() =>
    this.getColorByEstado(this.solicitud()?.estado));

  // Inputs/Outputs como funciones (NO decoradores)
  expediente = input.required<string>();
  cerrado = output<void>();
}
```

## Reglas Obligatorias

<Tabs>
  <TabItem label="Componentes">
    | Regla | Correcto | Incorrecto |
    |-------|----------|------------|
    | Standalone | *(default, no declarar)* | `standalone: true` |
    | Change detection | `OnPush` siempre | `Default` |
    | Inyección | `inject(Service)` | `constructor(private svc: Service)` |
    | Inputs | `input()` / `input.required()` | `@Input()` |
    | Outputs | `output()` | `@Output()` |
    | Control flow | `@if`, `@for`, `@switch` | `*ngIf`, `*ngFor` |
    | Estilos | Tailwind CSS | CSS puro para layout |
  </TabItem>
  <TabItem label="Estado">
    | Regla | Correcto | Incorrecto |
    |-------|----------|------------|
    | Estado local | `signal()` | `BehaviorSubject` |
    | Estado derivado | `computed()` | Getter / pipe manual |
    | Async data | `resource()` | `async` pipe con Subject |
    | Formularios | Reactive Forms (`FormBuilder`) | Template-driven forms |
  </TabItem>
  <TabItem label="Routing">
    | Regla | Correcto | Incorrecto |
    |-------|----------|------------|
    | Carga de componentes | `loadComponent` (lazy) | Imports directos |
    | Guards | `CanActivateFn` | Class-based guards |
    | Interceptors | `HttpInterceptorFn` | Class-based interceptors |

## Native Control Flow

```html
<!-- @if — reemplaza *ngIf -->
@if (loading()) {
  <app-spinner />
} @else if (error()) {
  <div class="text-red-500">{{ error() }}</div>
} @else {
  <div>Contenido cargado</div>
}

<!-- @for — reemplaza *ngFor -->
@for (solicitud of solicitudes(); track solicitud.id) {
  <app-solicitud-card [solicitud]="solicitud" />
} @empty {
  <p>No hay solicitudes registradas.</p>
}

<!-- @switch — reemplaza ngSwitch -->
@switch (estado()) {
  @case ('RECEPCIONADA') { <span class="text-blue-500">Recepcionada</span> }
  @case ('RESPONDIDA') { <span class="text-green-500">Respondida</span> }
  @case ('VENCIDA') { <span class="text-red-500">Vencida</span> }
  @default { <span>{{ estado() }}</span> }
}
```

## SSR con Express

El frontend usa **Angular SSR** con Express 5.1 para renderizado del lado del servidor:

```typescript
// server.ts
import { APP_BASE_HREF } from '@angular/common';
import { CommonEngine } from '@angular/ssr/node';
import express from 'express';

const server = express();
const commonEngine = new CommonEngine();

server.get('*', (req, res, next) => {
  commonEngine
    .render({ bootstrap, documentFilePath, url: req.originalUrl })
    .then(html => res.send(html))
    .catch(err => next(err));
});
```

:::tip[SSR-Safe]
Los servicios que acceden a `localStorage` o `window` deben verificar la plataforma:
```typescript
private readonly platformId = inject(PLATFORM_ID);

if (isPlatformBrowser(this.platformId)) {
  localStorage.setItem('usuario', JSON.stringify(data));
}
```
:::

## Signals Reactivos para Estado de Dominio

Los componentes de detalle utilizan `computed()` de Angular Signals para derivar propiedades reactivas del estado de negocio sin suscripciones manuales:

```typescript
export class FuncionarioSolicitudDetalleComponent {
  // Signal base: solicitud cargada desde el backend
  solicitud = signal<Solicitud | null>(null);

  // Signal derivado: ID de la apelación TTAIP (si existe)
  idApelacion = computed(() => {
    const historial = this.solicitud()?.historialEstados;
    const eventoApelacion = historial?.find(
      h => h.estadoNuevo === 'APELADA'
    );
    return eventoApelacion?.referenciaExpediente ?? null;
  });

  // Signal derivado: alerta de silencio administrativo
  alertaSilencio = computed(() => {
    const sol = this.solicitud();
    if (!sol) return false;
    return sol.semaforo === 'NEGRO' && sol.estado !== 'RESPONDIDA';
  });
}
```

Este patrón ofrece dos ventajas técnicas:

1. **Granularidad en la detección de cambios**: Angular recalcula `computed()` solo cuando las signals de las que depende emiten nuevos valores, optimizando los ciclos de `OnPush`.
2. **Eliminación de pipes asíncronos**: Las propiedades derivadas se leen sincrónicamente en el template con `idApelacion()` sin necesidad de `| async` ni suscripciones explícitas.

## Rutas Dinámicas y RenderMode.Client

Para habilitar la navegación interactiva entre el expediente SAIP y el expediente TTAIP sin romper la compilación SSR, se registró la ruta `/funcionario/apelaciones/:expediente` y se configuró como `RenderMode.Client` en las rutas del servidor:

```typescript
// app.routes.server.ts
export const serverRoutes: ServerRoute[] = [
  // Rutas que dependen de parámetros dinámicos → RenderMode.Client
  { path: 'funcionario/apelaciones/:expediente', renderMode: RenderMode.Client },
  // Rutas pre-renderizables → RenderMode.Prerender
  { path: '**', renderMode: RenderMode.Prerender },
];
```

`RenderMode.Client` indica a Angular que esta ruta debe renderizarse exclusivamente en el navegador, evitando que el pre-renderizador intente resolver parámetros dinámicos (`:expediente`) durante la compilación estática. En el componente de detalle del funcionario, un `routerLink` interactivo permite navegar al expediente TTAIP:

```html
@if (idApelacion()) {
  <a [routerLink]="['/funcionario/apelaciones', idApelacion()]"
     class="inline-flex items-center gap-1 text-blue-600
            hover:text-blue-800 transition-colors">
    Ver expediente TTAIP
    <ng-icon name="heroArrowTopRightOnSquare" size="16" />
  </a>
}
```

:::tip[Compatibilidad SSR]
`RenderMode.Client` es la solución idiomática de Angular 21 para rutas que dependen de datos del navegador. No afecta al rendimiento de las rutas pre-renderizadas y evita el fallback a errores 404 durante `ng build`.
:::
