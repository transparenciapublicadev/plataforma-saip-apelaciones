El frontend cuenta con **8 servicios HTTP** que encapsulan toda la comunicación con el backend REST API. Todos usan `inject(HttpClient)` y `environment.apiUrl`.

## Patrón de Servicio

```typescript
@Injectable({ providedIn: 'root' })
export class SolicitudService {
  private readonly http = inject(HttpClient);
  private readonly apiUrl = environment.apiUrl + '/solicitudes';

  getSolicitudes(): Observable<Solicitud[]> {
    return this.http.get<Solicitud[]>(this.apiUrl);
  }

  crear(solicitud: SolicitudCreate): Observable<Solicitud> {
    return this.http.post<Solicitud>(this.apiUrl, solicitud);
  }
}
```

    }

## Modelos TypeScript

Los modelos se generan desde el **OpenAPI spec** del backend y se re-exportan con tipos `Required<>`:

```typescript
// solicitud.model.ts
import type { SolicitudDTO } from '../api/types';

export type Solicitud = Required<SolicitudDTO> & {
  respuesta?: Respuesta;
  apelacion?: Apelacion;
  documentos?: Documento[];
};

// Tipo de creación (solo campos del cliente)
export interface SolicitudCreate {
  asunto: string;
  descripcion: string;
  ciudadanoId: number;
  entidadId: number;
  formatoDigital: boolean;
  copiaSimple: boolean;
}
```

:::tip[API-First]
Los tipos TypeScript se derivan del OpenAPI spec para mantener consistencia con el contrato del backend. Al cambiar el esquema del backend, se regeneran los tipos automáticamente en el frontend.
:::
