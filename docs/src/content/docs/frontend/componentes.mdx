## Componentes Documentales

`DocumentUploadComponent` y `DocumentListComponent` se reutilizan en el detalle
ciudadano de SAIP, el detalle funcionario y el expediente TTAIP.

- Validan PDF, JPG, PNG o TXT hasta 10 MB antes de invocar el backend.
- Muestran estados de carga, éxito y errores RFC 9457.
- Descargan exclusivamente mediante `/api/documentos/{id}/download`.
- Limpian el input después de una carga correcta.
- Ocultan eliminación en páginas ciudadano, funcionario y TTAIP; el backend
  conserva la autorización definitiva.
- No exponen `storageKey`, bucket, endpoint ni rutas internas.

## Patrones Comunes

### Estado con Signals

```typescript
// Todos los componentes usan este patrón
solicitudes = signal<Solicitud[]>([]);
loading = signal(false);
error = signal<string | null>(null);
searchTerm = signal('');

// Estado derivado
filteredSolicitudes = computed(() =>
  this.solicitudes().filter(s =>
    s.expediente.includes(this.searchTerm()) ||
    s.asunto.toLowerCase().includes(this.searchTerm().toLowerCase())
  )
);
```

### Badges de Estado

```typescript
getEstadoClass(estado: string): string {
  const clases: Record<string, string> = {
    RECEPCIONADA: 'bg-blue-100 text-blue-800',
    EN_REVISION: 'bg-yellow-100 text-yellow-800',
    RESPONDIDA: 'bg-green-100 text-green-800',
    DENEGADA: 'bg-red-100 text-red-800',
    VENCIDA: 'bg-gray-800 text-white',
  };
  return clases[estado] ?? 'bg-gray-100 text-gray-800';
}
```

### Formularios Reactivos

```typescript
private readonly fb = inject(FormBuilder);

form = this.fb.group({
  asunto: ['', [Validators.required, Validators.maxLength(200)]],
  descripcion: ['', [Validators.required, Validators.maxLength(2000)]],
  entidadId: [null as number | null, Validators.required],
});

onSubmit() {
  if (this.form.invalid) return;
  this.loading.set(true);
  this.solicitudService.crear(this.form.value)
    .subscribe({
      next: () => this.router.navigate(['/ciudadano']),
      error: (err) => this.error.set(err.message),
      complete: () => this.loading.set(false),
    });
}
```
