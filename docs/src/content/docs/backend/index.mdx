El módulo **backend** es el corazón de la Plataforma SAIP. Expone una API REST que sirve como fuente de datos central para los módulos frontend y mobile, publicando un contrato OpenAPI como interfaz formal.

## Stack Tecnológico

<CardGrid>
  <Card title="Spring Boot 4.0.6" icon="rocket">
    Framework principal con autoconfiguración, embedded Tomcat y soporte para el JDK configurado.
  </Card>
  <Card title="Java 25" icon="seti:java">
    Versión configurada en `backend/pom.xml` mediante `java.version`.
  </Card>
  <Card title="MySQL + JPA" icon="seti:db">
    Spring Data JPA con Hibernate y dialecto `MySQLDialect`. DDL auto-update en desarrollo.
  </Card>
  <Card title="Spring Security" icon="approve-check-circle">
    JWT (JJWT 0.12.6) + BCrypt(12) + autorización basada en roles.
  </Card>
</CardGrid>

| Propiedad | Valor |
|-----------|-------|

## Ejecutar el Backend

```bash
# Requisito: MySQL corriendo en localhost:3306/saip_db
cd backend
./mvnw spring-boot:run        # Linux/macOS
.\mvnw.cmd spring-boot:run    # Windows
```

:::note
`application.properties` conserva fallbacks exclusivamente locales para `DB_USERNAME`, `DB_PASSWORD` y `JWT_SECRET`. En cualquier despliegue, sobrescribir obligatoriamente `DB_PASSWORD` y `JWT_SECRET` mediante variables de entorno o un gestor de secretos.
:::
