Los ViewModels siguen un patrón estricto: **UiState inmutable** + **Events** para efectos secundarios + **StateFlow** para observación reactiva.

## Patrón Obligatorio

### Estructura de un ViewModel

```kotlin
// 1. UiState — siempre @Immutable data class
@Immutable
data class CitizenDashboardUiState(
    val solicitudes: List<Solicitud> = emptyList(),
    val apelaciones: List<Apelacion> = emptyList(),
    val loading: Boolean = false,
    val error: String? = null,
    val estadisticas: EstadisticasCiudadano? = null,
)

// 2. Events — sealed interface para one-shot
sealed interface CitizenDashboardEvent {
    data class MostrarMensaje(val mensaje: String) : CitizenDashboardEvent
    data class NavegarADetalle(val expediente: String) : CitizenDashboardEvent
    data object CerrarSesion : CitizenDashboardEvent
}

// 3. ViewModel con UseCases inyectados
class CitizenDashboardViewModel(
    private val getSolicitudes: GetSolicitudesUsuarioUseCase,
    private val getApelaciones: GetApelacionesUsuarioUseCase,
    private val getEstadisticas: GetEstadisticasCiudadanoUseCase,
) : ViewModel() {

    private val _uiState = MutableStateFlow(CitizenDashboardUiState())
    val uiState: StateFlow<CitizenDashboardUiState> = _uiState.asStateFlow()

    private val _events = MutableSharedFlow<CitizenDashboardEvent>()
    val events: SharedFlow<CitizenDashboardEvent> = _events.asSharedFlow()

    init {
        cargarDatos()
    }

    fun cargarDatos() {
        viewModelScope.launch {
            _uiState.update { it.copy(loading = true, error = null) }
            try {
                getSolicitudes(usuarioId).collect { solicitudes ->
                    _uiState.update { it.copy(solicitudes = solicitudes) }
                }
            } catch (e: Exception) {
                _uiState.update { it.copy(error = e.message) }
            } finally {
                _uiState.update { it.copy(loading = false) }
            }
        }
    }

    fun seleccionarSolicitud(expediente: String) {
        viewModelScope.launch {
            _events.emit(CitizenDashboardEvent.NavegarADetalle(expediente))
        }
    }
}
```

                    is CitizenDashboardEvent.CerrarSesion ->
                        onLogout()
                }
            }
        }

        // ... UI
    }

    class CrearSolicitudUseCase(
        private val repo: SolicitudRepository
    ) {
        suspend operator fun invoke(params: Params): Solicitud =
            repo.crearSolicitud(params.toSolicitud())
    }

    class LoginUseCase(
        private val authRepo: AuthRepository,
        private val credentialStorage: CredentialStorage,
    ) {
        suspend operator fun invoke(
            identificador: String,
            password: String,
        ): AuthResult {
            val result = authRepo.login(identificador, password)
            if (result is AuthResult.Success) {
                credentialStorage.guardarSesion(result.usuario)
            }
            return result
        }
    }

## Reglas del Patrón

| Regla | Detalle |
|-------|---------|
| `@Immutable` en UiState | Optimiza recomposición de Compose |
| `StateFlow` para estado | `.asStateFlow()` para inmutabilidad externa |
| `SharedFlow` para eventos | One-shot, no se replayan en recomposición |
| `copy()` para actualizaciones | NUNCA mutar directamente el UiState |
| `viewModelScope.launch` | Cancela coroutines automáticamente |
| `collectAsStateWithLifecycle` | OBLIGATORIO, nunca `collectAsState()` |
| UseCases via `factory` | Nueva instancia por cada invocación |
