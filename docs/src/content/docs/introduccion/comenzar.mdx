## Configuración del Backend

<Steps>

1. **Crear la base de datos MySQL**

   ```sql
   CREATE DATABASE saip_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. **Configurar variables de entorno**

   El backend usa variables externalizadas para secrets. Configurar en el sistema o en un archivo `.env`:

   ```properties
   DB_USERNAME=root
   DB_PASSWORD=tu_password
   JWT_SECRET=tu_secret_key_minimo_256_bits
   ```

   :::caution
   **NUNCA** hardcodear credenciales en el código fuente. Usar siempre variables de entorno.
   :::

3. **Ejecutar el backend**

   <Tabs syncKey="os">
     <TabItem label="Windows">
       ```powershell
       cd saip-backend
       .\mvnw.cmd spring-boot:run
       ```
     </TabItem>
     <TabItem label="Linux / macOS">
       ```bash
       cd saip-backend
       ./mvnw spring-boot:run
       ```
     </TabItem>
   </Tabs>

   El servidor se levantará en `http://localhost:8080`.

4. **Verificar que funciona**

   ```bash
   curl http://localhost:8080/v3/api-docs
   ```

   Debe retornar el OpenAPI spec en formato JSON.

</Steps>

## Configuración del Frontend

<Steps>

1. **Instalar dependencias**

   ```bash
   cd saip-frontend
   npm install
   ```

2. **Iniciar el servidor de desarrollo**

   ```bash
   npm start
   ```

   Angular CLI iniciará `ng serve` en `http://localhost:4200`.

3. **Verificar la conexión con el backend**

   Asegurarse de que el backend está corriendo en `:8080`. El frontend se conecta a la API REST configurada en los services.

</Steps>

:::tip
El frontend usa **SSR con Express** para producción. En desarrollo, `ng serve` proporciona hot-reload automático.
:::

## Configuración del Mobile

<Steps>

1. **Abrir en Android Studio**

   Abrir la carpeta `MiSAIP/` como proyecto en Android Studio.

2. **Configurar Firebase**

   El archivo `google-services.json` debe estar en `MiSAIP/app/`. Configurar Firebase Auth y FCM en la consola de Firebase.

3. **Configurar la URL del backend**

   En `MiSAIP/gradle.properties`, verificar que `REST_BASE_URL` apunte al backend:

   ```properties
   REST_BASE_URL=http://10.0.2.2:8080/api/
   ```

   :::note
   `10.0.2.2` es la IP del host desde el emulador Android. Para dispositivo físico, usar la IP de la máquina.
   :::

4. **Compilar y ejecutar**

   <Tabs syncKey="os">
     <TabItem label="Windows">
       ```powershell
       cd MiSAIP
       .\gradlew.bat assembleDebug
       ```
     </TabItem>
     <TabItem label="Linux / macOS">
       ```bash
       cd MiSAIP
       ./gradlew assembleDebug
       ```
     </TabItem>
   </Tabs>

</Steps>

## Ejecución de Tests

<Tabs syncKey="module">
  <TabItem label="Backend" icon="setting">
    ```bash
    cd saip-backend
    ./mvnw test          # Linux/macOS
    .\mvnw.cmd test      # Windows
    ```
    Ejecuta JUnit 5 + Mockito. Cobertura objetivo: 80%.
  </TabItem>
  <TabItem label="Frontend" icon="laptop">
    ```bash
    cd saip-frontend
    npm test
    ```
    Ejecuta Vitest para tests unitarios y de componentes.
  </TabItem>
  <TabItem label="Mobile" icon="rocket">
    Importante: compilar **todos** los módulos antes de testear para evitar cache stale de Gradle.

    ```bash
    cd MiSAIP
    # Paso 1: Compilar TODOS los módulos
    ./gradlew clean compileDebugKotlin

    # Paso 2: Ejecutar tests
    ./gradlew test
    ```

    :::caution
    Los módulos `core/network`, `core/data`, `core/database` y `core/common` **no tienen tests unitarios**. Solo `core/domain` y `app/` contienen tests.
    :::
  </TabItem>
</Tabs>

## Verificación Completa

Para verificar que todo el entorno está configurado correctamente:

```bash
# Terminal 1 — Backend
cd saip-backend && ./mvnw spring-boot:run

# Terminal 2 — Frontend
cd saip-frontend && npm start

# Terminal 3 — Mobile (build)
cd MiSAIP && ./gradlew assembleDebug
```

Una vez los tres módulos estén corriendo, el sistema estará disponible:

| Módulo | URL / Método |
|--------|-------------|
| Backend API | `http://localhost:8080/api/` |
| OpenAPI Spec | `http://localhost:8080/v3/api-docs` |
| Frontend Web | `http://localhost:4200` |
| Mobile | Emulador o dispositivo Android |
