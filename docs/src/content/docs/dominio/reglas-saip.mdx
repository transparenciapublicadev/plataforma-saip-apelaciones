## Marco Legal

La Ley N° 27806 — **Ley de Transparencia y Acceso a la Información Pública** — regula el derecho de toda persona a solicitar información a entidades de la Administración Pública.

:::caution[Fuente oficial mandatoria]
El documento `Flujo SAIP Y TTAIP_081942.docx` es la referencia oficial de reglas de negocio. La versión consolidada vive en `docs/business-rules/SAIP_TTAIP_REGLAS_NEGOCIO.md` y las brechas contra el sistema actual en `docs/business-rules/SAIP_TTAIP_BRECHAS.md`.
:::

## Reglas de Negocio

### BR-SAIP-001 — Plazo Máximo

<Card title="10 días hábiles" icon="warning">
El plazo máximo de atención de una solicitud SAIP es de **10 días hábiles**. El conteo inicia el **día hábil siguiente** a la recepción (día de recepción = día 0). Si la SAIP se presenta fuera del horario laboral, se considera recibida el siguiente día hábil y el plazo inicia al día hábil posterior.
</Card>

### BR-SAIP-002 — Días Hábiles

Se excluyen del conteo:
- Sábados y domingos
- **14 feriados nacionales peruanos:**

| Fecha | Feriado |
|-------|---------|
| 1 de enero | Año Nuevo |
| Jueves y Viernes Santos | Semana Santa (variable) |
| 1 de mayo | Día del Trabajo |
| 7 de junio | Batalla de Arica |
| 23 de junio | Día del Campesino |
| 28–29 de julio | Fiestas Patrias |
| 6 de agosto | Batalla de Junín |
| 30 de agosto | Santa Rosa de Lima |
| 8 de octubre | Combate de Angamos |
| 1 de noviembre | Día de Todos los Santos |
| 8 de diciembre | Inmaculada Concepción |
| 9 de diciembre | Batalla de Ayacucho |
| 25 de diciembre | Navidad |

### BR-SAIP-003 — Subsanación

La entidad puede requerir subsanación solo dentro de los **2 primeros días hábiles** desde la recepción de la solicitud.

El flujo formal queda registrado como una observación SAIP: motivo, fecha de observación, fecha límite de subsanación, comentario o documento del ciudadano, estado y trazabilidad. Al observar, la solicitud pasa a `PENDIENTE_INFORMACION`; al subsanar dentro del plazo vuelve a `EN_REVISION`; si vence sin subsanación, queda cerrada administrativamente como `CONCLUIDA` bajo el modelo actual.

### BR-SAIP-004 — Liquidación de Costos

Si aplica cobro por costos de reproducción, la liquidación debe emitirse **a más tardar el día 9** del plazo.

### BR-SAIP-005 — Silencio Administrativo Negativo

Si transcurren más de **10 días hábiles** sin respuesta de la entidad, opera el **silencio administrativo negativo** y la solicitud pasa a estado `VENCIDA`. Esto habilita automáticamente el derecho del ciudadano a apelar.

### BR-SAIP-006 — Plazo para Apelar

El documento oficial contiene una diferencia interna que debe resolverse antes de modificar código: una tabla menciona **15 días calendario**, pero el Art. 34.2 citado en el mismo documento establece **15 días hábiles** para denegatoria expresa. Para denegatoria tácita o silencio administrativo negativo no existe plazo perentorio.

:::caution[No cambiar sin decisión legal/producto]
No hardcodear ni cambiar validaciones de plazo de apelación hasta que el equipo confirme si el criterio productivo será días calendario o días hábiles para denegatoria expresa.
:::

### BR-SAIP-007 — Consentimiento y canal de notificación

La creación de una SAIP exige consentimiento expreso para el tratamiento de datos personales y debe registrar el canal formal de notificación elegido por el ciudadano.

| Campo | Estado de implementación | Regla |
| --- | --- | --- |
| `consentimientoDatosPersonales` | Cubierto | Obligatorio y validado antes de crear la SAIP. |
| `canalNotificacion` | Cubierto | Permite `CORREO_ELECTRONICO`, `CASILLA_ELECTRONICA`, `PLATAFORMA` y `FISICA`. |

:::note[Casilla electrónica]
`CASILLA_ELECTRONICA` ya está soportada como canal elegido. Las constancias, acuses y fallback automático pertenecen al motor de notificaciones y se mantienen como brecha separada.
:::

## Semáforo de Estado

El sistema muestra un indicador visual del estado del plazo:

| Color | Rango | Significado |
|-------|-------|-------------|
| 🟢 Verde | Días 0–5 | En plazo |
| 🟡 Ámbar | Días 6–8 | Próximo a vencer |
| 🔴 Rojo | Días 9–10 | Urgente |
| ⚫ Negro | >10 días | Vencido (Silencio Administrativo) |

```java
// Implementación del semáforo
public static String calcularSemaforo(long diasTranscurridos) {
    if (diasTranscurridos <= 5) return "VERDE";
    if (diasTranscurridos <= 8) return "AMBAR";
    if (diasTranscurridos <= 10) return "ROJO";
    return "NEGRO";
}
```

## Tipos de Respuesta

| TipoRespuesta | Estado resultante | ¿Apelable? |
|---------------|-------------------|------------|
| `ENTREGA_TOTAL` | `RESPONDIDA` | Sí |
| `ENTREGA_PARCIAL` | `RESPONDIDA` | Sí |
| `DENEGACION_TOTAL` | `DENEGADA` | Sí |
| `SILENCIO_ADMINISTRATIVO` | `VENCIDA` | Sí |

:::note[Entrega total es apelable]
El ciudadano puede apelar incluso ante una entrega total si considera que la información entregada no es la que solicitó o está incompleta.
:::

## Causales de Denegación (Art. 15 Ley 27806)

1. Información clasificada como secreta en el ámbito militar o de inteligencia
2. Información clasificada como reservada (seguridad nacional)
3. Información confidencial (secreto bancario, tributario, comercial, industrial, tecnológico)
4. Información vinculada a investigaciones en trámite
5. Información preparada u obtenida para la defensa del Estado
6. Datos personales sensibles
7. Información protegida por secreto profesional
8. Información protegida por el privilegio de asesoría legal
9. Información que pueda afectar la seguridad de las personas

## Formato de Número SAIP

| Componente | Formato | Ejemplo |
|------------|---------|---------|
| Prefijo | `SAIP` | — |
| Año | `AAAA` | `2025` |
| Secuencia | `NNNNN` (5 dígitos, zero-padded) | `00512` |
| **Completo** | **`SAIP-AAAA-NNNNN`** | **`SAIP-2025-00512`** |

## Flujo de Estados

<Steps>
1. **RECEPCIONADA** — Solicitud ingresada al sistema
2. **EN_REVISION** — Funcionario asignado revisa la solicitud
3. **PENDIENTE_INFORMACION** — Observación formal pendiente de subsanación ciudadana (2 días hábiles)
4. **RESPONDIDA** — Entrega total o parcial de información
5. **DENEGADA** — Denegación total con fundamento legal
6. **CONCLUIDA** — Solicitud cerrada administrativamente
7. **VENCIDA** — Silencio administrativo negativo (>10 días hábiles)
</Steps>

:::caution[SAIP ≠ Expediente]
Una **Solicitud SAIP** es de primera instancia. Su número (`SAIP-AAAA-NNNNN`) **NO es un expediente**. El expediente (`NNNNN-AAAA-JUS/TTAIP`) solo se crea cuando el ciudadano apela ante el TTAIP.
:::
