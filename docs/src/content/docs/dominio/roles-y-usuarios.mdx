## Tipos de Usuario

El sistema SAIP define **4 roles** con accesos y capacidades diferenciadas:

<CardGrid>
  <Card title="Ciudadano" icon="person">
    Presenta solicitudes SAIP, recibe respuestas de entidades, y puede apelar ante el TTAIP si no está conforme.
  </Card>
  <Card title="Funcionario" icon="setting">
    Oficial de una entidad pública que recibe y responde solicitudes asignadas a su institución.
  </Card>
  <Card title="Miembro TTAIP" icon="approve-check-circle">
    Vocal del Tribunal de Transparencia que califica y resuelve recursos de apelación.
  </Card>
  <Card title="Administrador" icon="warning">
    Gestiona el sistema, usuarios, entidades y reportes globales.
  </Card>
</CardGrid>

## Jerarquía de Entidades (JPA JOINED)

```
Usuario (base abstracta)
  ├── Ciudadano      → dni, nombreCompleto, telefono, direccion
  ├── Funcionario    → nombreCompleto, cargo, area, telefono, entidad
  ├── MiembroTTAIP   → nombreCompleto, cargo, sala, especialidad
  └── Administrador  → nombreCompleto, rol, permisos
```

:::note[Herencia JOINED]
Cada tipo de usuario tiene su propia tabla en la base de datos (`ciudadanos`, `funcionarios`, `miembros_ttaip`, `administradores`) con una relación JOIN a la tabla base `usuarios`. Esto permite consultas específicas por tipo sin datos nulos.
:::

    | `dni` | `String (8)` | Documento Nacional de Identidad — único |
    | `nombreCompleto` | `String` | Nombre y apellidos |
    | `telefono` | `String` | Teléfono de contacto |
    | `direccion` | `String` | Dirección de notificación |
    | `solicitudes[]` | Relación | Solicitudes SAIP presentadas |
    | `apelaciones[]` | Relación | Recursos de apelación |
  </TabItem>
  <TabItem label="Funcionario">
    | Campo | Tipo | Descripción |
    |-------|------|-------------|
    | `nombreCompleto` | `String` | Nombre y apellidos |
    | `cargo` | `String` | Cargo en la entidad |
    | `area` | `String` | Área o unidad orgánica |
    | `telefono` | `String` | Teléfono institucional |
    | `entidad` | `Entidad` | Entidad pública (ManyToOne) |
    | `respuestas[]` | Relación | Respuestas a solicitudes |
  </TabItem>
  <TabItem label="MiembroTTAIP">
    | Campo | Tipo | Descripción |

    | `cargo` | `String` | Presidente de Sala / Vocal |
    | `sala` | `String` | Primera Sala / Segunda Sala |
    | `especialidad` | `String` | Área de especialización |
    | `resoluciones[]` | Relación | Resoluciones emitidas |
  </TabItem>
  <TabItem label="Administrador">

    | `nombreCompleto` | `String` | Nombre y apellidos |
    | `rol` | `String` | Rol administrativo |
